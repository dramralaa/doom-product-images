# doom-product-images

مستودع مستقل لاستضافة صور منتجات دوم (Public عمدًا - روابط raw.githubusercontent.com
منه مستخدمة مباشرة في رفعات هنجرستيشن/جاهز الحية، فلازم يفضل قابل للوصول العام).

> **⚠️ ملاحظة أمان دائمة:** أي تفاصيل تجارية/تعاقدية (أرقام عقود، عمولات، أسماء
> جهات اتصال، ماستر أسعار/تكلفة، ملفات مطابقة تحتوي بيانات مصدر ثالث) **ممنوع
> نهائيًا** تتحط هنا - الريبو ده صور بس. كل التفاصيل دي مكانها الريبو الخاص
> (private) المقابل.

## 🗂️ هيكل الملفات

| المسار | المحتوى |
|---|---|
| `by_juleb_code/<كود دوم>.jpg` | **المصدر المعتمد للاستخدام في أي رفع لأي منصة** - صور مطابقة بالباركود، باسمها = كود جوليب الداخلي (`data/products.json` → `code`). |
| `raw_vera_import/` | صور مصدرها خارجي (أرشيف تاريخي) - **متستخدمش مباشرة**، مصدر مطابقة فقط. |
| `hungerstation_orphaned_harvest/` | صور خام غير مربوطة بكود بعد. |
