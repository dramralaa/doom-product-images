# doom-product-images

مستودع مستقل لاستضافة صور منتجات دوم ومطابقتها بكود جوليب الداخلي، وتوثيق مسار
العمل الكامل لربط كتالوج دوم بمنصات التوصيل الخارجية (هنجرستيشن، جاهز شوبز/بيك).
منفصل عمدًا عن `juleb-daily-report` عشان لو الريبو الرئيسي اتقفل private
مستقبلاً، روابط الصور تفضل شغالة.

> **مرجع دائم:** لأي تفاصيل تجارية/تعاقدية (أرقام العقود، شروط العمولة، تواريخ)
> راجع قسم "🚚 مشروع ربط وتتبع مبيعات هنجرستيشن" و"تكامل جاهز/بيك" في
> `PROJECT_CONTEXT.md` بريبو `juleb-daily-report` - هذا الملف هنا تقني/تنظيمي بس.

## 🗂️ هيكل الملفات

| المسار | المحتوى |
|---|---|
| `by_juleb_code/<كود دوم>.jpg` | **المصدر المعتمد للاستخدام في أي رفع لأي منصة.** صور مطابقة 100% (بالباركود) وباسمها = كود جوليب الداخلي الحقيقي (`data/products.json` → `code`). |
| `raw_vera_import/` | الصور الأصلية من فيرا (2440 صورة)، بأسماء فيرا الداخلية - سجل تاريخي، **متستخدمش مباشرة**. |
| `hungerstation_active_raw/` *(قيد الإنشاء)* | صور خام من صفحة "إدارة المخزون" في بوابة شركاء هنجرستيشن (`partner-app.hungerstation.com`) للأصناف **النشطة** فقط، مع ملف فهرس (اسم الصورة/الاسم العربي/الكود الداخلي/الباركود). **مصدر أقوى من مطابقة فيرا** لأنه معتمد فعليًا على حساب دوم نفسه. |
| `vera master.xlsx` / `ماستر فيرا مع لينك الصور.xlsx` | تصدير فيرا الكامل (Internal Reference / Barcode / Name...) - مرجع مطابقة. |
| `manifest_verified_image_matches.json` | سجل كل مطابقة فعلية (كود دوم ↔ صورة) مع طريقة المطابقة - للشفافية والتتبع. |
| `doom_vera_barcode_overlap_full.json` | كل منتجات دوم اللي نفس باركودها موجود عند فيرا (2857 صنف)، سواء ليها صورة دلوقتي أو لأ - مرشحين لأي طلب صور مستقبلي. |
| `doom_novaplus_hungerstation_name_match.json` | 1181 صنف اتطابقوا بالباركود مع كتالوج صيدلية تانية شغالة فعليًا على هنجرستيشن - بيدي اسم إنجليزي/عربي **موثّق من طرف ثالث حقيقي** (مش تخمين). روابط الصور فيه (`dead_image_url`) **معطوبة عمدًا اتأكد منها - متتستخدمش**. |
| `Products_Missing_Images_AskKarim.xlsx` | قائمة أصناف مؤكد تطابقها مع فيرا لكن محتاجة صورة - جاهزة لو حبينا نطلب من كريم (مدير فيرا) صور إضافية. |

## 🏢 منصتين مختلفتين تمامًا - لازم نفرّق بينهم دايمًا

### 1. هنجرستيشن (Hungerstation) - عقد مباشر مع دوم
- **الحالة:** عقد موقّع (`OQ-0010821850`، 09/08/2026)، عمولة 12.5% (10% خدمة + 2.5% دفع إلكتروني)، دوم 2 مُفعّل، دوم 1 حساب مفتوح غير مُفعّل بعد.
- **الربط التقني:** **Assortment API فعّال فعليًا (RUNNING)** عبر Webhook `https://medova.juleb.com/hungerstation/catalog-webhook` - يعني **جوليب ↔ هنجرستيشن مربوطين ببعض تلقائيًا** لمزامنة الكتالوج (المنتجات نفسها/الأسعار الأساسية)، لكن Direct/Indirect Order API **غير مُفعّل** (الطلبات لسه بتوصل بطريقة تانية زي ما موثّق بالتفصيل في `PROJECT_CONTEXT.md`).
- **بوابة الإدارة اليدوية:** `partner-app.hungerstation.com/store-management` - فيها كل أصناف دوم (نشط/غير نشط)، بالكود الداخلي الحقيقي (لو الصنف مش من بواقي حساب تجريبي قديم)، الباركود، السعر، الصورة المستضافة عند هنجرستيشن نفسها.
- **الحالة الحالية (19 أغسطس 2026):** جاري سحب صور الأصناف النشطة من البوابة دي (بمساعدة سكريبت Gemini على جهاز صاحب المشروع) - هتترفع هنا في `hungerstation_active_raw/`.

### 2. جاهز شوبز / بيك (Jahez Shops / PIK) - عقد منفصل، بيك هي المشغّل التقني
- **الحالة:** في مرحلة التعاقد/الإعداد - عيّنة 30 صنف اتقبلت من منيرة (مسؤولة التكامل)، ملف Joining Requirements جاهز، جاري تجهيز الكتالوج الكامل.
- **⚠️ الربط التقني: لا يوجد أي تكامل/API بين جاهز/بيك وجوليب حاليًا.** يعني عكس هنجرستيشن تمامًا - **أي تحديث (رصيد، سعر، تفعيل/إيقاف صنف) هيكون يدوي بالكامل** لحد ما (لو حصل) نلاقي آلية تحديث تانية من بيك نفسها (راجع "مهام مؤجلة" تحت).
- **القالب:** ملف "ماستر" 24 عمود (`Product ID, SKU, Name English, Name Arabic, Description English, Description Arabic, Industry, Has Variants?, Parent?, Variant SKU, Has Color?, Has Size?, Color English, Color Arabic, Size English, Size Arabic, Price, Image#1-7`). أعمدة `Product ID, Industry, Has Variants?, Parent?, Variant SKU, Has Color?, Has Size?` = **"Leave it for us" - بيك هي اللي بتملاها، مش احنا**.
- **قاعدة صارمة (من بريد جوليب الرسمي):** عمود `SKU` لازم يكون **الكود الداخلي الحقيقي (`default_code`)** من جوليب - أي كود تاني (يدوي أو مولّد من المنصة) هيكسر التكامل.
- **سياسة أمان ثابتة:** استبعاد كامل لفئة "MEDICINE" من أي كتالوج يترفع لمنصة توصيل خارجية.
- **حقوق النشر:** أي اسم/وصف مسحوب من مصدر خارجي (هنجرستيشن أو غيره) يتعمله تعديل نصي بسيط (إعادة صياغة تحافظ على المعنى) قبل استخدامه في ملف بيك - مش نسخ حرفي.

## 🔄 منهجية مطابقة الصور (بالترتيب من الأقوى للأضعف)

1. **مباشر من حساب دوم على هنجرستيشن** (`hungerstation_active_raw/`) - أقوى مصدر، لأنه نفس حساب دوم بالظبط، مفيش وسيط.
2. **بالباركود مع كتالوج صيدلية تانية فعلاً على هنجرستيشن** (`doom_novaplus_hungerstation_name_match.json`) - موثوق للاسم العربي/الإنجليزي، **لكن روابط صوره معطوبة**.
3. **بالباركود مع فيرا** (`doom_vera_barcode_overlap_full.json` + `raw_vera_import/`) - موثوق للصورة، طالما نفس الباركود.

المطابقة دايمًا بالباركود (بعد تصفير أي أصفار زيادة على الطرفين) - **مش بالاسم ومش تخمين بصري** - عشان تكون موثوقة 100%.
