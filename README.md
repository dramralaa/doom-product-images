# doom-product-images

مستودع مستقل لاستضافة صور منتجات دوم (منفصل عمدًا عن `juleb-daily-report` عشان لو الريبو الرئيسي اتقفل private مستقبلاً، روابط الصور تفضل شغالة).

## الهيكل

- **`by_juleb_code/<كود دوم>.jpg`** - الصور المعيارية المعتمدة، مسمّاة بكود جوليب الداخلي لدوم (نفس عمود `code` في `data/products.json`). **ده المصدر اللي المفروض يُستخدم في أي رفع لأي منصة (بيك/هنجرستيشن/غيرها).**
- **`raw_vera_import/`** - الصور الأصلية زي ما وصلت من فيرا (2440 صورة)، بأسمائها الأصلية (كود فيرا الداخلي)، محفوظة كسجل تاريخي/مصدر - **متستخدمش مباشرة في أي رفع، استخدم `by_juleb_code/` بدلها.**
- **`vera master.xlsx`** - تصدير كامل من نظام فيرا (Internal Reference / Barcode / Name / GTIN...) اتستخدم كمرجع للمطابقة.
- **`manifest_verified_image_matches.json`** - سجل كل مطابقة تمت فعليًا بين كود دوم وصورة، مع طريقة المطابقة للشفافية.
- **`doom_vera_barcode_overlap_full.json`** - قائمة كاملة بكل منتجات دوم اللي ليها نفس الباركود موجود عند فيرا (سواء موجود لها صورة دلوقتي أو لأ) - مرجع مستقبلي لطلب صور إضافية.

## منهجية المطابقة

المطابقة اتعملت **بالباركود فقط** (مش تخمين بصري ومش بالاسم) عشان تكون موثوقة 100%:

1. مقارنة باركود/GTIN كل صنف في `vera master.xlsx` بباركود منتجات دوم في `data/products.json`.
2. لو فيه تطابق باركود → نجيب "Internal Reference" بتاع فيرا لنفس الصنف.
3. لو فيه صورة في `raw_vera_import/` باسم يطابق الـInternal Reference ده → يبقى عندنا صورة مؤكدة لمنتج دوم، وبتتنسخ لـ`by_juleb_code/<كود_دوم>.jpg`.

**النتيجة الحالية (17 أغسطس 2026):** من إجمالي 7962 منتج دوم، **2857 منتج ليهم نفس الباركود عند فيرا** (تأكيد فعلي لوجود موردين/منتجات مشتركة بين الصيدليتين)، و**89 منهم عندهم صورة مؤكدة جاهزة الآن** في `by_juleb_code/`. الباقي (2769 صنف) معروفين ومؤكدين كمنتجات مشتركة لكن لسه محتاجين صورة - مرشحين ممتازين لأي طلب صور مستقبلي من فيرا أو أي مصدر تاني.
